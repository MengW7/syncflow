## 任务状态机
### 1. 状态
| 状态 | 终态 | 含义 | 页面展示 |
| :--- | :--- | :--- | :--- |
| `pending` | 否 | 已创建任务，等待 Worker | 等待中 |
| `running` | 否 | Worker 正在处理 | 执行中 |
| `succeeded` | 是 | 全部行成功 | 成功 |
| `partial_succeeded` | 是 | 成功行与失败行同时存在 | 部分成功 |
| `failed` | 是 | 文件级失败，或所有数据行失败，或重试耗尽 | 失败 |
| `cancelled` | 是 | 在 pending / running 时取消成功 | 已取消 |

### 2. 状态转换条件
| 从 | 到 | 条件 |
| :--- | :--- | :--- |
| pending | running | Worker 从队列中拉取任务 |
| pending | cancelled | 用户操作取消，且Worker还没有拉取到任务 |
| running | cancelled | 用户操作取消，且Worker没有处理完 |
| running | succeeded | 处理结束，且fail_count=0 |
| running | partial_succeeded | 处理结束，且success_count>0, failure_count>0 |
| running | failed | 文件级失败，或success_count=0且failure_count>0 |
