## SyncFlow 需求疑问清单

| 编号 | 核心问题 | 影响范围 | 状态 | 结论 |
| :--- | :--- | :--- | :--- | :--- |
| **Q01** | CSV 到底导入哪种业务对象及固定表头是什么？ | 数据库设计、数据校验、导出接口 | **[已确认]** | V1.0 固定为商品（`product`），表头为 `sku,name,price,quantity`。 |
| **Q02** | CSV 编码、分隔符及表头格式要求？ | 文件解析器、错误码 | **[已确认]** | 仅限 UTF-8，逗号分隔。列名必须精准匹配，顺序不限。 |
| **Q03** | 空文件、仅表头、超行数、超大文件在哪层拦截？ | API 状态码、Worker 失败状态 | **[已确认]** | >10MB/非 CSV 接口直接同步报 4xx；0 字节空文件 Worker 标 FAILED；仅表头 0 行 Worker 标 SUCCEEDED；>10000 行 Worker 标 FAILED。 |
| **Q04** | 任务「成功/部分成功/失败」如何严密界定？ | 任务状态机、列表统计、前端展示 | **[已确认]** | **裁决**：全合法为 `SUCCEEDED`；有成有败为 `PARTIAL_SUCCEEDED`；文件级错误或有效行全错为 `FAILED`。 |
| **Q05** | 状态机是否包含 CANCELLED？ | 状态枚举、API 定义 | **[已确认]** | **裁决**：枚举包含 `CANCELLED`。 |
| **Q06** | 处理过程中是否需实时显示已处理行数？ | `jobs` 表结构、前端轮询设计 | **[待确认]** | 预留 `processed_rows`，Worker 每批（如 100 行）回写一次；前端详情页每 2s 轮询。 |
| **Q07** | 任务内“相同数据不重复写入”指整行还是业务主键？ | 数据库唯一约束设计 | **[已确认]** | PRD 中明确说明“任务内业务标识（SKU）唯一”，同一任务相同 SKU 记录错误行。 |
| **Q09** | 创建任务的事务边界与消息投递顺序？ | 技术设计、接口容错 | **[已确认]** | 落库 MySQL(PENDING) 成功后再投递 Redis；投递失败整单回滚报 500。 |
| **Q8** | 哪些错误可重试？重试粒度是整任务还是单行？ | `job_attempts` 表、Worker 消费 | **[已确认]** | 仅基础设施宕机/超时可重试（整个任务重跑）；数据校验/格式错误单次即死，不重试。 |
| **Q9** | 创建任务是一步完成还是分块/先传后建？ | OpenAPI 契约设计 | **[已确认]** | `POST /api/v1/jobs` 采用一步直传并快速返回 201 摘要信封。 |
| **Q10** | 列表排序与分页边界超出如何响应？ | 列表查询接口实现 | **[已确认]** | 默认 `created_at DESC`；`page_size` 范围 1~100，超出 100 或 ≤ 0 返回 `400 VALIDATION_ERROR`。 |
| **Q11** | 错误明细展示到什么程度？是否暴露文件路径？ | `job_errors` 字段、安全设计 | **[已确认]** | 记录行号、SKU、错误码及原始行片断 `raw_preview` |
| **Q12** | 前端核心路由与通用状态如何规划？ | 前端路由与交互规范 | **[已确认]** | 规划 `/`、`/jobs/new`、`/jobs/:id`、`/jobs/:id/errors` 四个页面，均需支持加载/空/错误三态。 |
