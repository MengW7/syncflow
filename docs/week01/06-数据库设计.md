## 数据库设计

### 6.1 任务主表 (jobs)

| 字段 | 类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | CHAR(36) | PK | job_id，UUID 字符串 |
| `status` | VARCHAR(32) | NOT NULL, INDEX | 任务状态枚举 |
| `original_filename` | VARCHAR(255) | NOT NULL | 客户端原始文件名，仅用于展示 |
| `stored_filename` | VARCHAR(255) | NOT NULL | 服务端规范化存储名，API 对外脱敏不返回 |
| `file_size_bytes` | BIGINT | NOT NULL | 上传文件字节数 |
| `file_sha256` | CHAR(64) | NOT NULL, INDEX | 文件内容 SHA256 摘要，用于溯源与查重 |
| `idempotency_key` | VARCHAR(64) | NULL, UNIQUE | 幂等键（V1.1），NULL 表示未提供 |
| `total_rows` | INT | NOT NULL DEFAULT 0 | 有效数据总行数（不含表头） |
| `success_count` | INT | NOT NULL DEFAULT 0 | 成功写入的记录行数 |
| `failure_count` | INT | NOT NULL DEFAULT 0 | 失败记录行数（文件级失败计为 0） |
| `error_code` | VARCHAR(64) | NULL | 文件级全局错误码 |
| `error_message` | VARCHAR(512) | NULL | 文件级错误的可读描述 |
| `attempt_count` | INT | NOT NULL DEFAULT 0 | 已执行重试次数 |
| `cancel_requested` | TINYINT(1) | NOT NULL DEFAULT 0 | 协作式取消请求标记，Worker 批处理中轮询 |
| `started_at` | DATETIME(3) | NULL | 任务首次进入 running 状态的 UTC 时间 |
| `finished_at` | DATETIME(3) | NULL | 任务进入终态（succeeded/failed/cancelled 等）的 UTC 时间 |
| `created_at` | DATETIME(3) | NOT NULL | 任务创建时间（UTC） |
| `updated_at` | DATETIME(3) | NOT NULL | 记录最后更新时间（UTC） |

- **索引规划**：
  - `idx_jobs_status_created (status, created_at DESC)`：加速任务列表按状态筛选及时间倒序分页。
  - `idx_jobs_sha256 (file_sha256)`：加速文件内容比对与历史溯源。

### 6.2 成功记录表 (job_records)

| 字段 | 类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | BIGINT | PK, AUTO_INCREMENT | 行自增 ID |
| `job_id` | CHAR(36) | NOT NULL, INDEX | 所属任务 UUID |
| `row_number` | INT | NOT NULL | CSV 中的物理行号（表头行为0） |
| `sku` | VARCHAR(64) | NOT NULL | 商品业务唯一标识 |
| `name` | VARCHAR(255) | NOT NULL | 商品名称 |
| `price` | DECIMAL(12,2) | NOT NULL | 单价 |
| `quantity` | INT | NOT NULL DEFAULT 0 | 数量，非负整数 |
| `category` | VARCHAR(64) | NULL | 商品类目，允许为空 |
| `created_at` | DATETIME(3) | NOT NULL | 记录写入时间（UTC） |
| `updated_at` | DATETIME(3) | NOT NULL | 记录更新时间（UTC） |

- **约束与索引**：
  - 唯一约束 `uk_job_sku (job_id, sku)`：确保单次任务内 SKU 不重复，作为并发安全底线。
  - 联合索引 `idx_records_job_id (job_id, id)`：覆盖索引，用于成功记录的高效分页查询。

### 6.3 错误明细表 (job_errors)

| 字段 | 类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | BIGINT | PK, AUTO_INCREMENT | 自增内部 ID |
| `job_id` | CHAR(36) | NOT NULL, INDEX | 所属任务 UUID |
| `row_number` | INT | NULL | 发生错误的行号 |
| `sku` | VARCHAR(64) | NULL | 出错行的 SKU |
| `error_code` | VARCHAR(64) | NOT NULL | 错误码 |
| `error_message` | VARCHAR(512) | NOT NULL | 业务的错误排查原因 |
| `raw_preview` | VARCHAR(1024) | NULL | 原始行数据截断预览 |
| `created_at` | DATETIME(3) | NOT NULL | 记录写入时间（UTC） |
| `updated_at` | DATETIME(3) | NOT NULL | 记录更新时间（UTC） |

- **索引规划**：
  - 联合索引 `idx_errors_job_id (job_id, id)`：用于按任务高效分页拉取错误日志。

### 6.4 执行尝试记录表 (job_attempts)

| 字段 | 类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | BIGINT | PK, AUTO_INCREMENT | 自增主键 |
| `job_id` | CHAR(36) | NOT NULL, INDEX | 所属任务 UUID |
| `attempt_no` | INT | NOT NULL | 尝试序号（从 1 开始递增） |
| `status` | VARCHAR(32) | NOT NULL | 本轮执行状态：running / succeeded / failed / cancelled |
| `error_code` | VARCHAR(64) | NULL | 本轮失败时的错误码 |
| `error_message` | VARCHAR(512) | NULL | 本轮失败的脱敏原因描述 |
| `success_count` | INT | NOT NULL DEFAULT 0 | 本轮累计成功处理行数 |
| `failure_count` | INT | NOT NULL DEFAULT 0 | 本轮累计失败行数 |
| `started_at` | DATETIME(3) | NOT NULL | 本轮尝试启动时间（UTC） |
| `finished_at` | DATETIME(3) | NULL | 本轮尝试结束时间（UTC） |
| `created_at` | DATETIME(3) | NOT NULL | 创建时间（UTC） |
| `updated_at` | DATETIME(3) | NOT NULL | 更新时间（UTC） |

- **约束说明**：
  - 唯一约束 `uk_job_attempt (job_id, attempt_no)`：单次任务的执行尝试序号全局唯一，全链路日志通过 `job_id + attempt_no` 实现精准关联追踪。
