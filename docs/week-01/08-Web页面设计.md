## Web页面设计

### 1. 页面路由
| 路由 | 页面 | 作用 |
| :--- | :--- | :--- |
| `/` | `JobListPage` | 任务列表，包含任务总览表格、分页控件、状态筛选栏 |
| `/jobs/new` | `JobCreatePage` | 选择 CSV 并创建任务 |
| `/jobs/:jobId` | `JobDetailPage` | 展示任务详情信息 |
| `/jobs/:jobId/errors` | `JobErrorPage` | 展示错误明细分页 |

### 2. 任务列表
核心功能：展示任务总览表格、分页控件，进行状态筛选
* **交互说明**：
  * 支持按任务状态（`pending`、`running`、`succeeded`、`partial_succeeded`、`failed`、`cancelled`）筛选。
  * 列表按创建时间倒序排列，点击跳转到详情。
  * 顶部提供全局“新建任务”操作入口。

### 3. 任务创建
核心功能：创建任务
* **交互说明**：
  * **前端预检**：校验文件扩展名是否为 `.csv`，校验文件体积是否超限。
  * **提交与反馈**：文件上传后，界面给出成功提示并自动跳转至该任务的详情页。

### 4. 任务详情
核心功能：展示文件名、任务状态、任务统计
* **交互说明**：
  * **指标展示**：展示总行数、成功行数、失败行数、耗时及状态。
  * **状态轮询**：若处于 `pending` 或 `running` 状态，前端启动短轮询；进入终态后自动停止轮询。
  * **操作控制**：当任务未结束时提供“取消任务”按钮；存在异常行时提供“查看错误明细”入口。

### 5. 任务失败
核心功能：展示任务错误行号、错误码、原因
* **交互说明**：
  * **明细表格**：呈现行号、错误码及失败原因。
