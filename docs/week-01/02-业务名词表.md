| 名词 | 英文 / 字段 | 定义 |
| :--- | :--- | :--- |
| 任务 | job | 一次 CSV 导入的完整生命周期对象，拥有唯一 job_id |
| 任务编号 | job_id | UUID，创建接口立即返回，不需要等待任务完成 |
| 数据操作人员 | operator | 上传 CSV、查看结果与错误明细的使用者，本系统不实现登录 |
| 系统维护人员 | maintainer | 看日志、定位失败、维护本地环境的角色，本系统不实现登录 |
| API | api | FastAPI 进程：接收上传、写任务、投递队列、提供查询。 |
| Worker | worker | 独立进程：从 Redis 取任务，流式校验并分批写入 MySQL |
| 任务队列 | task_queue | 用于承载异步任务流转的 Redis 队列，API 负责写入任务，Worker 负责阻塞拉取并执行 |
| 幂等 | idempotency | 同一 Idempotency-Key 在 TTL 内重复创建，返回已有任务而不新建重复任务 |
| 文件摘要 | file_hash | 记录文件内容的 SHA-256，防止文件重复上传，结果复用 |
| 业务标识 | biz_key | 一行数据在同一任务内的唯一业务键，用于防重复写入 |
| 成功记录 | job_record | 成功通过校验并写入业务表的一行数据 |
| 错误记录 | job_error | 某一行或文件失败的原因 |
| 执行尝试 | job_attempt | Worker 对某任务的一次执行，含起止时间与结果 |
| 部分成功 | partial_succeeded | 同一任务内既有成功行也有失败行 |
| 成功 | succeeded | 五失败行，数据全部成功写入 |
| 排队中 | pending | 任务已创建，但还在Redis中排队，未写入Worker |
| 执行中 | running | 任务正在Worker中运行 | 
| 失败 | failed | 文件异常，或所有数据全部错误 |
| 取消 | cancelled | 文件还在pending/running状态时被用户取消 |
| 可重试错误 | retryable | 超时、连接闪断等暂时性错误，可重试 |
| 不可重试错误 | non_retryable | 表头错误、超限、校验失败等，重试仍会失败 |
| 表头 | header | CSV的表头，用于文件检查 |
| 文件行号 | row_number | CSV中的行号，方便用户定位源文件 |
| 批次大小 | batch_size | 单批次提交的最大行数 |
| 最大执行次数 | MAX_JOB_ATTEMPTS | 最大尝试次数，超过则失败 | 
| 超时时间 | lease_expires_at | Worker超时则直接停止，避免占用过多系统资源 |
