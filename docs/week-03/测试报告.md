## 未覆盖项

- 前端没有测试脚本。`npm test` 不存在。页面验收靠 `npm run lint`、`npm run build` 和创建、详情、错误明细的手工走查，不在这次 `pytest` 里。
- 这次没有再跑 Docker Compose 的整条链路。创建即返回和 Worker 终态由 `test_jobs_api.py::test_create_job_success` 与 `test_worker.py::test_worker_reaches_success_partial_and_failed` 覆盖。本机不能绑定宿主端口 8000，所以没有用 Compose 发布的 API 重测。
- 10MB 用例检查的是创建接口的字节上限，不把这 10MB 内容当合法 CSV 去解析。行数上限另有 10000 / 10001 用例。
- 幂等键、自动重试、取消和导出没有实现，也没有用例。
- 批量写入失败断言的是 `INTERNAL_ERROR` 和批号文案，没有单独的 `DB_WRITE_FAILED`。
- 超时回收只测了 Worker 启动时的一次。没有周期扫描，也没有断言回收时删除已提交的 `sync_records`。
- 宿主机 Worker 和 Compose Worker 同时消费同一队列的路径不一致，没有自动化用例。运行时不要同时开两个消费者。
